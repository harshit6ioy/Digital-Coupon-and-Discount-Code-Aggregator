 Digital Coupon & Discount Code Aggregator


 
This project is a web-based platform designed to help users discover, submit, and manage online coupons and discount codes. Built using HTML, CSS, Tailwind CSS, JavaScript, PHP, and MySQL, it offers a seamless experience for both users and administrators.​

The application features a user-friendly interface where visitors can browse the latest coupons on the homepage. Registered users have the ability to add new coupons through a dedicated form, enhancing the platform's offerings. The search functionality allows users to find coupons by keyword or store, making it easier to locate desired deals.​

To foster community engagement, the platform includes a reviews section where users can share their experiences and feedback. The contact page provides a channel for users to reach out with inquiries or support requests.​

User authentication is implemented, allowing individuals to register and log in securely. Passwords are hashed using password_hash() and verified with password_verify() to ensure security. Once logged in, users can access additional features and have the option to log out securely.​

The backend is powered by PHP, handling form submissions and interactions with the MySQL database. The database schema includes tables for users, coupons, and reviews, structured to maintain data integrity and support the application's functionality.​

To set up the project locally, clone the repository and place it within your web server's root directory (e.g., htdocs for XAMPP). Create a MySQL database and import the provided SQL schema. Update the db/config.php file with your database credentials. Start your web server and navigate to http://localhost/coupon-aggregator-website/index.html to access the application.​

This platform aims to simplify the process of finding and sharing discount codes, providing a centralized hub for users to save money while shopping online
